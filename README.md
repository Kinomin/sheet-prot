# 自動座席表作成ツール（β版）

学校の座席替えでよくある悩み（固定席・NGペア・男女交互・前回と同じ席の禁止など、複数の条件を同時に満たす座席をランダムに作る）を、ブラウザだけで解決するツールです。

**→ https://kinomin.github.io/sheet-prot/**

## できること

- **テンプレート管理**：クラス（HR）・授業ごとに、名簿・座席レイアウト・教室備品・固定席／NGペアを保存
- **座席表履歴**：1つのテンプレートで、期間ごとの座席表を何枚でも作成・複製・管理
- **名簿の読み込み**：CSV・Excel（.xlsx）に対応。ふりがな→ローマ字を自動生成（手動修正も可）
- **座席レイアウト編集**：列数・行数の自動生成後、1席単位で削除・復元・追加。教室備品（黒板・教卓・入口・出口）もドラッグで配置
- **座席固定・NGペア**：座席レイアウトを模したグリッドから直接クリックして座席を固定。前後左右の隣接を禁止するNGペアも登録可能
- **ランダム配置**：①固定席→②固定生徒→③NGペア→④前回と同じ席禁止→⑤男女交互→⑥残りをランダム、という優先順位を**絶対条件**として配置。条件を満たせない場合は部分的な配置を採用せず、原因を提示して中止
- **Undo / Redo**：60操作分の元に戻す・やり直し
- **生徒側／教員側の自動切替**：座席データは生徒側基準の1系統のみを保持し、教員側（教卓から見た図＝180度回転）はその場で自動生成
- **印刷プレビュー**：画面中央で仕上がりを確認してから印刷。固定バッジなど編集用の表示は印刷されません
- **端末間の引き継ぎ**：同じGoogleアカウントであれば、職員室のパソコンでも自宅でも同じデータで作業できます
- **会員種別**：無料会員／プレミアム会員（500円/年・Stripe決済）

## データの保存場所

| データ | 保存場所 |
|---|---|
| 生徒の名簿・座席表 | 端末のブラウザ内（IndexedDB）＋ **利用者自身のGoogleドライブのアプリ専用領域** |
| アカウント・会員種別 | Supabase（当方のデータベース） |
| カード情報 | Stripe（当方は保持しません） |

**生徒の個人情報は運営側のサーバーに保存されません。** Googleドライブの「アプリ専用領域（appDataFolder）」は本アプリ専用の隠し領域で、ドライブ内のほかのファイルにはアクセスできません。学校で扱う名簿を第三者のデータベースへ預けずに済む構成にしています。

詳細は[プライバシーポリシー](./privacy.html)をご覧ください。

## 構成

```
ブラウザ（GitHub Pages）
  ├─ Google Drive appDataFolder … 名簿・座席表（利用者本人のアカウント内）
  └─ Supabase
       ├─ Auth（Googleログイン）
       ├─ profiles テーブル（会員種別。RLSと列レベル権限で保護）
       └─ Edge Functions
            ├─ create-checkout-session … 申し込み
            ├─ create-portal-session   … 解約・支払い方法の変更
            └─ stripe-webhook          … 署名検証して会員種別を更新
```

会員種別を書き換えられるのはStripeのwebhookを受ける関数だけで、ブラウザ側からは更新できないようデータベースの権限で塞いでいます。

## 公開・セットアップ

[**DEPLOY.md**](./DEPLOY.md) に、Google Cloud・Supabase・Stripeの設定からデプロイ、公開前チェックリストまでまとめています。

> **⚠️ シークレットの扱い**
> Stripeのシークレットキー（`sk_...`）とSupabaseの`service_role`キーは、`index.html`に書かず、Supabaseのシークレットにのみ登録してください。このリポジトリは公開されているため、コミットすると第三者に読まれます。
> `index.html`に置く`supabaseUrl` / `supabaseAnonKey` / `googleClientId`は、いずれもブラウザに配布される前提の公開値です。

設定前でも「お試しログイン」で全機能を確認できます（この場合、データはその端末内のみに保存されます）。

## 使い方

1. https://kinomin.github.io/sheet-prot/ を開く
2. 会員種別を選んでGoogleアカウントでログイン
3. 「新しいテンプレート」を作成
4. 「名簿管理」で名簿を読み込む（CSV/Excel）
5. 「座席レイアウト」「固定席・NGペア」で条件を設定
6. 「座席表履歴」から座席表を作成し、「ランダム配置」または手動で配置
7. 「印刷 / PDF」でプレビューを確認して印刷

## β版として把握している制約

| 項目 | 現状 |
|---|---|
| 同時編集 | 複数の端末で同時に編集した場合、後から同期したほうの内容が残ります（テンプレート単位で更新時刻を比較） |
| オフライン | 端末内には保存され続けますが、クラウドへの反映は次にオンラインになったときです |
| バックアップ | 明示的な書き出し機能はありません（印刷・PDF保存で控えを残せます） |
| 共有 | 複数の教職員で1つの名簿を共有する機能はありません |

## 技術メモ

- 依存ライブラリなし・ビルドステップなしの単一HTMLファイル（Vanilla JS）。Supabaseも公式SDKを使わず`fetch`で呼び出しています
- `.xlsx` の読み込みは `DecompressionStream('deflate-raw')` によるZIP展開と `DOMParser` によるXML解析を自前実装
- 端末間の同期はテンプレート単位のJSONファイル＋削除記録（tombstone）で、更新時刻を比較して統合します
- 設計判断・修正履歴は [`実装メモ.md`](./実装メモ.md) を参照してください
