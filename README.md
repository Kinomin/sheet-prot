# 自動座席表作成ツール（プロトタイプ）

学校の教室でよくある「座席替え」の悩み（固定席・NGペア・男女交互・前回と同じ席の禁止など、複数の条件を同時に満たす座席をランダムに作る）を、ブラウザだけで解決するツールです。

ビルド不要・単一HTMLファイルで動作し、外部ライブラリやサーバー通信は一切使っていません。ブラウザで開けばそのまま動きます。

**→ [`index.html`](./index.html) をダブルクリック、またはブラウザにドラッグ＆ドロップして開いてください。**
**→ または https://kinomin.github.io/sheet-prot/ をブラウザで開いてください（GitHub Pages）。**

## できること

- **テンプレート管理**：クラス（HR）・選択授業ごとに、名簿・座席レイアウト・教室備品・固定席／NGペアを保存
- **座席表履歴**：1つのテンプレートで、期間ごとの座席表を何枚でも作成・複製・管理
- **名簿の読み込み**：CSV・Excel（.xlsx）に対応（.xlsxも外部ライブラリ不使用の自前パーサで読み込み）。ふりがな→ローマ字を自動生成（手動修正も可）
- **座席レイアウト編集**：列数・行数の自動生成後、1席単位で削除・復元・追加。教室備品（黒板・教卓・入口・出口）もドラッグで配置
- **座席固定・NGペア**：座席レイアウトを模したグリッドから直接クリックして座席を固定。前後左右の隣接を禁止するNGペアも登録可能
- **ランダム配置**：①固定席→②固定生徒→③NGペア→④前回と同じ席禁止→⑤男女交互→⑥残りをランダム、という優先順位を絶対条件として配置。条件を満たせない場合は部分的な配置を採用せず、原因を提示して中止
- **Undo / Redo**：60操作分の元に戻す・やり直しに対応
- **生徒側／教員側の自動切替**：座席データは生徒側（生徒から見た配置）基準の1系統のみを保持し、教員側（教卓から見た図＝180度回転した配置）はその場で自動生成。印刷時にどちらかを選べます
- **印刷プレビュー**：印刷ボタンを押すと画面中央にプレビューを表示し、「はい、印刷する」を押すまで実際の印刷は行われません。固定バッジなど編集用の表示は印刷（プレビュー含む）には出ません
- **IndexedDB永続化**：ブラウザを閉じてもデータが保持されます。座席表のデータは外部へ送信されません
- **ログイン・会員種別**：Googleアカウントでのログイン、無料会員／プレミアム会員（500円/年・Stripe決済）の選択、法人契約の案内。設定アイコンからアカウント設定・ログアウト・問い合わせ

## 使い方

1. [`index.html`](./index.html) をブラウザで開く
2. 会員種別を選んでGoogleアカウントでログイン
3. ホーム画面から「新しいテンプレート」を作成、またはサンプルテンプレートを開く
4. 「名簿管理」で名簿を読み込む（CSV/Excel）
5. 「座席レイアウト」「固定席・NGペア」で条件を設定
6. 「座席表履歴」から座席表を作成し、「ランダム配置」または手動でドラッグ＆ドロップして配置
7. 「印刷 / PDF」でプレビューを確認して印刷

## セットアップ（ログイン・決済を有効にする）

`index.html` の先頭にある `APP_CONFIG` を書き換えます。**ここに入れるのは公開して問題のない値だけです。**

```js
const APP_CONFIG={
  googleClientId:"",        // Google OAuth クライアントID（ウェブ）
  stripePaymentLink:"",     // Stripe の Payment Link URL
  corporateContactUrl:"",   // 法人契約の問い合わせ先URL
  supportEmail:"",          // 問い合わせ先メール
  premiumPriceLabel:"500円 / 年",
};
```

| 項目 | 取得場所 | 補足 |
|---|---|---|
| `googleClientId` | Google Cloud Console → APIとサービス → 認証情報 → OAuth 2.0 クライアントID（ウェブ） | 「承認済みのJavaScript生成元」に `https://kinomin.github.io` を登録。公開前提の値なのでコミット可 |
| `stripePaymentLink` | Stripeダッシュボード → 商品を作成（500円/年） → Payment Link を発行 | 決済完了後の遷移先を `https://kinomin.github.io/sheet-prot/?checkout=success` に設定してください |
| `corporateContactUrl` / `supportEmail` | 任意の問い合わせ先 | 未設定の場合は案内ダイアログ内に設定方法が表示されます |

未設定でも「お試しログイン」で全機能を確認できます。

> **⚠️ 会員種別の判定について**
> 本ツールはサーバーを持たない静的サイトのため、会員種別はブラウザの localStorage に保存しています。
> ブラウザ内の値は利用者自身が書き換えられるため、**これだけでは課金の有無を根拠に機能制限をかけることはできません。**
> 課金と機能を確実に結びつけるには、Stripe の webhook を受け取って会員状態を保存・照会するサーバー
> （例：Cloud Functions + Firestore）が別途必要です。差し替え地点として `AUTH.setPlan()` と
> `AUTH.refreshPlanFromServer()` を用意しています。
> なお **Stripeのシークレットキー（`sk_...`）は絶対にこのファイルへ書かないでください。**

## 技術メモ

- 依存ライブラリなし・ビルドステップなしの単一HTMLファイル（Vanilla JS）
- `.xlsx` の読み込みは `DecompressionStream('deflate-raw')` によるZIP展開と `DOMParser` によるXML解析を自前実装（SheetJS等の外部ライブラリ不使用）
- データ永続化は生の IndexedDB API を使用
- 詳しい実装状況・設計判断・今後の課題は [`実装メモ.md`](./実装メモ.md) を参照してください
