# 自動座席表作成ツール（プロトタイプ）

学校の教室でよくある「座席替え」の悩み（固定席・NGペア・男女交互・前回と同じ席の禁止など、複数の条件を同時に満たす座席をランダムに作る）を、ブラウザだけで解決するツールです。

ビルド不要・単一HTMLファイルで動作し、外部ライブラリやサーバー通信は一切使っていません。ブラウザで開けばそのまま動きます。

**→ [`座席表ツール_プロトタイプ.html`](./座席表ツール_プロトタイプ.html) をダブルクリック、またはブラウザにドラッグ＆ドロップして開いてください。**

## できること

- **テンプレート管理**：クラス（HR）・選択授業ごとに、名簿・座席レイアウト・教室備品・固定席／NGペアを保存
- **座席表履歴**：1つのテンプレートで、期間ごとの座席表を何枚でも作成・複製・管理
- **名簿の読み込み**：CSV・Excel（.xlsx）に対応（.xlsxも外部ライブラリ不使用の自前パーサで読み込み）。ふりがな→ローマ字を自動生成（手動修正も可）
- **座席レイアウト編集**：列数・行数の自動生成後、1席単位で削除・復元・追加。教室備品（黒板・教卓・入口・出口）もドラッグで配置
- **座席固定・NGペア**：座席レイアウトを模したグリッドから直接クリックして座席を固定。前後左右の隣接を禁止するNGペアも登録可能
- **ランダム配置**：①固定席→②固定生徒→③NGペア→④前回と同じ席禁止→⑤男女交互→⑥残りをランダム、という優先順位を絶対条件として配置。条件を満たせない場合は部分的な配置を採用せず、原因を提示して中止
- **Undo / Redo**：60操作分の元に戻す・やり直しに対応
- **生徒側／教員側の自動切替**：座席データは生徒側（生徒から見た配置）基準の1系統のみを保持し、教員側（教卓から見た図＝180度回転した配置）はその場で自動生成。印刷時にどちらかを選べます
- **印刷プレビュー**：印刷ボタンを押すと画面中央にプレビューを表示し、「はい、印刷する」を押すまで実際の印刷は行われません。固定バッジなど編集用の表示は印刷（プレビュー含む）には出ません
- **IndexedDB永続化**：ブラウザを閉じてもデータが保持されます。データは外部へ送信されません

## 使い方

1. [`座席表ツール_プロトタイプ.html`](./座席表ツール_プロトタイプ.html) をブラウザで開く
2. ホーム画面から「新しいテンプレート」を作成、またはサンプルテンプレートを開く
3. 「名簿管理」で名簿を読み込む（CSV/Excel）
4. 「座席レイアウト」「固定席・NGペア」で条件を設定
5. 「座席表履歴」から座席表を作成し、「ランダム配置」または手動でドラッグ＆ドロップして配置
6. 「印刷 / PDF」でプレビューを確認して印刷

## 技術メモ

- 依存ライブラリなし・ビルドステップなしの単一HTMLファイル（Vanilla JS）
- `.xlsx` の読み込みは `DecompressionStream('deflate-raw')` によるZIP展開と `DOMParser` によるXML解析を自前実装（SheetJS等の外部ライブラリ不使用）
- データ永続化は生の IndexedDB API を使用
- 詳しい実装状況・設計判断・今後の課題は [`実装メモ.md`](./実装メモ.md) を参照してください
